# Close Block

1. Run `./scripts/lifeos/validate-art-context.sh`
2. Update checkpoint: completed, partial, pending, next action
3. `git status` and `git diff`
4. Commit if stable
5. List Danny authorization items if any

Report honest blockers — do not declare done with open P0s.
