# Import Reference

1. Copy original to `docs/source/raw/design/` or appropriate subfolder
2. Compute SHA-256 checksum
3. Update `docs/source/SOURCE_IMPORT_MANIFEST.md`
4. Update `docs/source/SOURCE_INDEX.md`
5. Create normalized index if PDF/visual
6. Update checkpoint

Do not delete prior versions.
