# Prepare Artistic Brief

1. Read checkpoint and `docs/design/LIFEOS_ART_CONTEXT_MANIFEST.md`
2. Identify surface, node, owners (read-only)
3. Load mandatory docs for task type
4. Draft brief: objective, references, composition, hierarchy, color, material, typography, motion, haptics, constraints, DoD
5. Flag items requiring Danny approval
6. Save to `docs/design/evidence/brief_<surface>.md`

Do not implement. Do not call Figma MCP.
