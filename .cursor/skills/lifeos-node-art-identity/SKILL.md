# Node Art Identity

## Trigger
Node-specific theming, Salud/Finanzas/Personal/Hogar identity, accent semantics.

## Documents to read
- `docs/design/NODE_ART_IDENTITIES.md`
- `docs/design/ART_DIRECTION_MASTER.md`

## Procedure
1. Select node from canonical list
2. Define accent semantics (not full palette takeover)
3. Map to tokens — white field remains dominant
4. Validate contrast and emergency exception rules
5. Document in NODE_ART_IDENTITIES.md

## Outputs
- Node token overrides
- Identity brief section

## Limits
- Node personality ≠ separate app
- Emergency node: clarity over decoration

## Success criteria
Node recognizable in <3s; global DNA intact.
