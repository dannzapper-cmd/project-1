## DNA global

| Principio | Regla |
|---|---|
| Blanco | Arquitectura predominante — vivo, no clínico |
| Negro | Texto, cifras, símbolos, precisión |
| Arcoíris | Vocabulario semántico por nodo/acción/estado |
| Cognitive Glass | Cristal selectivo con contraste |
| Luz reactiva | Highlight sigue movimiento/presión cuando aporta vida |
| Diversión | Inteligente, táctil — no infantil ni casino |

## Registros

- **Registro de Vacío:** aire, calma, espacio blanco estructurado
- **Registro de Objeto Vivo:** LIAH, Quick Dial, confirmaciones, objetos con presencia

## Materiales (adopción selectiva)

| Material | Adoptar | Rechazar |
|---|---|---|
| Neumorphism | Presión, masa en controles | Bajo contraste, app entera neumo |
| Glassmorphism | Planos, profundidad contextual | Cristal universal, WCAG roto |
| Claymorphism | Alegría táctil puntual | Infantilización permanente |
| Brutalism | Momentos editoriales | Gramática base |
| Spatial UI | Capas, continuidad | Copiar gafas AR en teléfono |
