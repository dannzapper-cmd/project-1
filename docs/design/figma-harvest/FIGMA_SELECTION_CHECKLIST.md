# Figma Selection Checklist

Complete before each MCP call.

## Pre-call

- [ ] Call number matches `FIGMA_SIX_CALL_PLAN.md`
- [ ] Remaining monthly budget confirmed (whoami + plan)
- [ ] Figma file URL recorded
- [ ] License verified for Community resources
- [ ] Score ≥75/100 on selection matrix
- [ ] Frames consolidated into single page/section
- [ ] Layers/components/variables named clearly
- [ ] Exact extraction list written
- [ ] Prompt filled from `FIGMA_PROMPT_TEMPLATE.md`
- [ ] Output paths created in `raw/SPRINT_FIGMA_001/`
- [ ] Danny approval timestamp recorded
